# Architecture

На данный момент у нас монолит ASP.NET, Nginx и PostgreSQL.

## Project Structure

У нас монорепозиторий, причем лихой.
Идея в следующем:

- Объединить фронт и бэк так, чтобы в них не пришлось ничего менять.
- У обоих проектов есть непересекающиеся директории и top-level файлы (из-за разности стеков) и мы берем на себя смелость смешать их в одну кучу.
- При желании, проекты всегда можно разрезать обратно, не меняя в них ничего\*.
- корневой package.json выступает у в роли cli обертки для всего что есть и что понадобиться в будущем.

_\*на стороне фронта мы для красоты переименовали папку src во frontend, это единственное что надо будет поправить обратно._

## Project Infrastructure

На данный момент у нас нет докера и всего такого.

Приложение собирается в один единственный бинарник (+ папка со статикой).
Этот бинарник запаковывается в systemd service.

Соответственно деплой будет сводится к cборке, заливке и перезапуске systemd юнита.  
В процессе автоматизация этого через gitlab ci, но пока все на простеньком баш-скрипте [deploy_stage.sh(WIP)](../deploy_stage.sh)
